# 三字经儿童学习游戏

把 AI Passport 变成一本口袋里的诵读启蒙机的三键小游戏。整部《三字经》内嵌在固件里——404 句、101 课——不联网、不插卡、不连手机也能玩。

这个应用也顺带示范了本仓库反复强调、但很容易做错的三件事：**重新设计界面**而不是沿用 demo 外壳、**把中文字库裁到只留用得到的字**、以及**把游戏逻辑留在电脑上**以便脱离真机测试。

## 功能

- **全文内置**。404 句、1212 字、565 个不重复汉字，按每课 4 句分成 101 课。运行时不读取任何外部数据，经文本身就是一个生成的 C 数组。
- **接句闯关**。每课出 3 道题：第 *i* 题显示某一句，问下一句是哪一句，给三个选项。干扰项只从**别的课**里取，光凭语感蒙不出来。
- **错题本**。答错的句子记在位图里；错题本一次最多抽 6 句重练，重练时答对的句子会被销账。
- **认字卡**。三格田字格把当前这一句逐字放大到 32 px，下面用整课的两行六字排印。
- **星星**。每课最多 3 颗，首次作答就答对一题得一颗。**只增不减**：重练不会把已有的星星降下来。
- **断点续学**。星星、错题位图和认字卡位置存在 NVS 里，共 156 字节，带魔术字节、版本号和校验和。
- **顶栏电量**。读不到电量时显示 `--`，不会画出一个假数字。
- **六个板载合成音效**（移动、进入、返回、答对、答错、通关），由 RTTTL 字符串现场合成，固件里不放任何音频素材。

## 交互

三个键通吃全部操作。有两条全局规则：上/下在**当前页面内**移动光标；确定**长按**永远是"退回上一级"。

**首页——四个入口：开始学习、认字卡、错题本、设置。**

- **上/下（短按）**：移动菜单光标。
- **确定（短按）**：进入选中的入口。
- 错题本里一句错题都没有时按确定，只会响一声拒绝音并留在原地，而不是进一个空页面。

每一行右侧还有一列状态：下一个要学的课号（101 课全过关后显示"从头复习"）、认字卡当前停在第几句、错题本里积了多少句。底栏汇总星星总数与已过关课数。

**闯关页。**

- **上/下（短按）**：在三个选项之间移动。
- **确定（短按）**：作答。作答后页面会短暂锁定并显示对错，免得连按的手指把下一题也答了。
- **确定（长按）**：返回首页（成绩页也用它退出）。

**认字卡。**

- **上/下（短按）**：上一句 / 下一句。
- **确定（短按）**：跳到下一课的第一句。若一句按一下，读完 404 句要按 404 下；已经停在最后一课时按确定会响一声拒绝音，不会绕回开头。
- **确定（长按）**：返回首页。

**设置。**

- **上/下（短按）**：在行之间移动。
- **确定（短按）**：切换音效，或启动两步走的进度重置。
- **确定（长按）**：返回首页。

两行下面是一块信息面板，写着这套经文的分量（404 句 · 1212 字 · 101 课）以及固件的来处。

清空进度不可逆，所以要走两步：第一次按确定只把这一行变成红色警告并改写底栏提示，**再按一次**才真动手；中途按其它任何键都算反悔。

## 出题模型

一课就是连续 4 句。对第 `L` 课，第 `i` 题的题面是第 `4L+i` 句，答案是紧随其后的第 `4L+i+1` 句。第 2 题会用到第 `4L+3` 句，它是存在的——所以 101 课每课都恰好出满 3 题，最后一课也不会越界。

一个干扰项要被接受，必须同时满足：下标合法、不是题面也不是答案、不与题面同课、并且不与题面文案、答案文案或已选中的选项重复。候选项由一个固定种子的线性同余发生器抽取，随机试探 64 次都失败就线性扫描兜底。因为种子只由 `(课号, 题号)` 决定，同一课永远生成同样的三道题——这正是主机测试能成立、以及错题重练能针对某一句重新出题的前提。

错题重练复用的就是同一套出题函数：把答错的那一句当作答案，它的上一句当作题面。

支撑这套模型的两条不变量是**检查出来的**，不是假设出来的：经文行数必须是 4 的倍数（404 = 4 × 101）；相邻两句文案不能相同（否则一道题有两个正确答案）。一句三个汉字等于 9 个 UTF-8 字节加结束符，这个长度由生成器固定成常量。

## 进度与持久化

存下去的是一条定长结构，而不是文本格式——这样损坏或截断的记录会被直接拒绝，不会被"应用一半"：

| 字段 | 长度 | 含义 |
| --- | --- | --- |
| `magic` | 1 字节 | `0x53`，先快速判断"这是不是我们的数据" |
| `version` | 1 字节 | 格式版本，当前为 1 |
| `card_line` | 2 字节小端 | 认字卡读到第几句 |
| `stars` | 101 字节 | 每课星星数，0–3 |
| `wrong` | 51 字节 | 错题位图（`(404+7)/8`） |
| `checksum` | 1 字节 | 尾部校验和 |

共 156 字节。反序列化时魔术字节、版本、长度、校验和**任一不符**就整体拒绝，并且不动调用方的结构体。记录一课时取"原有星星"与"本次星星"的较大值，所以重练只有好处没有坏处。

## 界面与字库

界面是从零写的，没有沿用基线测试菜单和它的 `ui_pixel` 外壳。视觉是宣纸加淡墨的课堂感：纸白页面、深墨顶栏（放标题与电量）、首页一块竹简招牌，当前选中项用朱红。

渲染中文必须有真正含这些字的字库——LVGL 自带的 Montserrat 一个汉字都没有。`assets/fonts/` 里的三档子集从 Noto Sans CJK SC 裁出，16 / 24 / 32 px、4 bpp、不压缩，覆盖 785 个码点。这个清单是**从经文和界面文案里推出来的**，不是拍脑袋列的；并且逐个码点对着母字体的字符映射核过，缺失 0。流水线与代价见配套的经验条目。

有两个细节值得单独点出来，因为它们是所有做中文界面的人都会踩的坑：

- **字表是生成出来的，不是手写的。** 生成器把经文里出现的字和界面自身字符串里的字，连同可打印 ASCII 一起取并集——以后加一个菜单标签，不会静默地变成空白文字。
- **C 源码体积不等于 Flash 占用。** 三份生成的 `.c` 加起来约 3.7 MB 的十六进制字面量，但编译后的点阵只占 571 KB Flash。照着文件列表估预算会差出六倍。

## 实现地图

应用代码全部新增，位于 `main/`；BSP 原样复用，未作修改。

| 文件 | 职责 |
| --- | --- |
| `main/szj_text.c`、`.h` | 生成物：404 句经文与文本形状常量 |
| `main/szj_text_util.c`、`.h` | 在生成数组之上的取句、取课辅助函数 |
| `main/szj_quiz.c`、`.h` | 出题与判分（纯逻辑） |
| `main/szj_session.c`、`.h` | 一次练习的状态机（纯逻辑） |
| `main/szj_progress.c`、`.h` | 星星、错题位图、序列化（纯逻辑） |
| `main/szj_store.c`、`.h` | NVS 命名空间与整块读写 |
| `main/szj_sound.c`、`.h` | 六个音效，包在 RTTTL 播放器之上 |
| `main/rtttl_player.c`、`.h` | 合成音频，复用自 `demo/tetris-game` |
| `main/szj_ui.c`、`.h` | 主题、页面骨架，以及列表行/选项行/田字格控件 |
| `main/szj_home.c`、`szj_lesson.c`、`szj_card.c`、`szj_settings.c` | 四个页面 |
| `main/szj_app.c`、`.h` | 按键语义与页面跳转 |
| `main/main.c` | 应用入口：拉起 BSP、存储、音效，再加载界面 |
| `tools/sanzijing/gen_content.py` | 经文文本 → `szj_text.c` |
| `tools/sanzijing/gen_font.py` | 字符清单与字库裁剪 |
| `tests/test_szj_*.c` | 四个纯逻辑模块的主机测试 |

四个纯逻辑模块——文本辅助、出题、会话、进度——不包含 ESP-IDF、LVGL 或 NVS 的头文件，因此能在电脑上编译运行。只有界面、存储和入口碰硬件。

## 构建与验证

用仓库统一的验证门构建：

```bash
./tools/validate.sh --static      # 仓库检查与主机测试
./tools/validate.sh --firmware    # 冷编译并产出合并镜像
```

本次记录到的构建结果：

- **固件门：通过。** 应用镜像 1,348,800 字节，位于 8,323,072 字节的 factory 分区，**剩余 84%**。合并镜像 1,414,336 字节，从 `0x0` 写入。
- **主机测试：通过。** 四个新测试（`test_szj_text_util`、`test_szj_quiz`、`test_szj_progress`、`test_szj_session`）已接入 `--static`，覆盖文本形状不变量、选项合法性与确定性、序列化往返（含损坏输入），以及完整的会话状态机。
- **仓库检查：通过**（`check_repo.py`、`actionlint`，以及 BSP 的按键、LVGL 初始化、音频三个测试）。
- **内存：** DRAM 用 147,984 / 321,296 字节（46%），空闲 173 KB。代码占 527,628 字节；字库与经文数组都在 `.rodata`，从 Flash 直读，不占 RAM。
- 已知的本地限制：既有的四个 `test_demo_*_runtime` 测试在本机链接失败，因为它们依赖 GNU 链接器丢掉未定义的 LVGL 桩符号，而本机的宿主链接器不做这件事。同样的失败在纯净检出上可以复现，与本应用无关。

## 尚未在真机验证

开发过程中没有烧录过，所以下面这些仍需真机确认：屏幕与圆角遮罩、三键 ADC 阶梯的手感与消抖、ES8311 音效、CW2017 电量读数、真实断电后的 NVS 持久化，以及长时间反复切页时 LVGL 内存池的实际余量。
